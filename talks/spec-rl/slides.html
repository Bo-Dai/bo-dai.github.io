Background
Markov Decision Processes (MDPs)

\(\mathcal{M} = \langle \mathcal{S}, \mathcal{A}, r, T, \mu, H/\gamma \rangle\)

  • State space: \(\mathcal{S}\)
  • Action space: \(\mathcal{A}\)
  • Reward: \(r:\mathcal{S}\times\mathcal{A}\to\mathbb{R}\)
  • Transition: \(T:\mathcal{S}\times\mathcal{A}\to\Delta(\mathcal{S})\)
  • Initial distribution: \(\mu\)
  • Policy: \(\pi(\cdot|s):\mathcal{S}\to\Delta(\mathcal{A})\)
\[ V^\pi(s) := \mathbb{E}_{T,\pi}\Bigl[\textstyle\sum_{t=0}^{\infty}\gamma^t r(s_t,a_t)\,\Big|\,s_0=s\Bigr] \]
\[ Q^\pi(s,a) := \mathbb{E}_{T,\pi}\Bigl[\textstyle\sum_{t=0}^{\infty}\gamma^t r(s_t,a_t)\,\Big|\,s_0=s,a_0=a\Bigr] \]

Finite-horizon: \(V_h^\pi, Q_h^\pi\) with \(\sum_{t=h}^{H-1}\) instead.

\[ \max_\pi\; J(\pi) = \mathbb{E}_{\mu(s)}\bigl[V^\pi(s)\bigr] \]
the RL objective

Model-free RL
(Deep) Q-learning

Dynamic programming via the Bellman recursion:

\[ Q(s,a) = R(s,a) + \gamma \sum_{s'} T(s'|s,a)\,\max_{a'} Q(s',a') \]

TD update

\[ Q_t(s,a) = Q_{t-1}(s,a) + \alpha\Bigl(R(s,a) + \gamma\max_{a'}Q(s',a') - Q_{t-1}(s,a)\Bigr) \]

Deep version

\[ \theta_t = \theta_{t-1} + \alpha\Bigl(R(s,a) + \gamma\max_{a'}Q_{t-1}(s',a') - Q_{t-1}(s,a)\Bigr)\nabla_\theta Q(s,a) \]
Spectral Representation-based RLModel-free · 7
Model-free RL
Policy gradient

Direct policy optimization:

\[ J(\pi_\theta) = \sum_{s} d^{\pi_\theta}(s)V^{\pi_\theta}(s) = \sum_s d^{\pi_\theta}(s)\sum_a \pi_\theta(a|s)\,Q^{\pi_\theta}(s,a) \]

Policy gradient

\[ \nabla_\theta J(\theta) = \sum_s d^\pi(s)\sum_a Q^\pi(s,a)\,\pi_\theta(a|s)\nabla_\theta\log\pi_\theta(a|s) = \mathbb{E}_{T,\pi}\bigl[Q^\pi(s,a)\nabla_\theta\log\pi_\theta(a|s)\bigr] \]

PG update  (→ natural PG, soft actor-critic, …)

\[ \theta_t = \theta_{t-1} + \alpha\,\mathbb{E}_{T,\pi}\bigl[Q^\pi(s,a)\nabla_\theta\log\pi_\theta(a|s)\bigr] \]

Model-free RL
Model-free RL: pros & cons

Pros

  • Modeling: easy to combine with function approximators (deep nets) and gradient-based learning.

Cons

  • Exploration: hard to capture uncertainty with arbitrary nonlinear functions.
  • Planning: no global-convergence guarantee for the optimal policy with general nonlinear functions.

Model-based RL
The model-based RL loop

Three instantiations of the same loop — differing only in the model class:

Generic MBRL

Estimate the dynamics model and reward; model predictive control on the learned model.

LQR

Estimate a linear dynamics model and quadratic reward; optimize the estimated LQR.

Deep MBRL / world model

Estimate a deep world model and reward; MPC on the learned model.

Stochastic nonlinear control as an MDP

Stochastic nonlinear control

\[ \min_\pi\;\mathbb{E}_\pi\Bigl[\textstyle\sum_{h=1}^{H} r(s_h,a_h)\Bigr]\quad \text{s.t.}\;\; s_{h+1} = f(s_h,a_h) + \epsilon_h,\;\; \epsilon_h\sim\mathcal{N}(0,\sigma^2 I) \]

MDP reformulation  \(\mathcal{M} = \langle\mathcal{S},\mathcal{A},r,T,\mu,H\rangle\)

\[ T(s'|s,a) \;\propto\; \exp\Bigl(-\frac{\|s'-f(s,a)\|_2^2}{2\sigma^2}\Bigr) \]
\[ T(s'|s,a) \;\propto\; \bigl\langle \phi_\omega(f(s,a)),\, \phi_\omega(s') \bigr\rangle_{\mathcal{N}(0,\sigma^{-2}I)},\qquad \phi_\omega(x) = [\cos(\omega^\top x),\,\sin(\omega^\top x)] \]
Gaussian kernel = inner product of random Fourier features
Spectral Representation-based RLControl · 15
Control
Factorized dynamics ⇒ linear Q-functions

Transition and reward factorize with \(\phi(s,a)\):

\[ T(s'|s,a) = \langle \phi(s,a),\, \mu(s') \rangle,\qquad r(s,a) = \langle \phi(s,a),\, \theta_r\rangle \]

Integration representable:

\[ \int V^\pi_{h+1}(s_{h+1})\,T(s_{h+1}|s_h,a_h)\,ds_{h+1} = \Bigl\langle \phi(s_h,a_h),\, \int V^\pi_{h+1}(s_{h+1})\,\mu(s_{h+1})\,ds_{h+1}\Bigr\rangle_{\mathcal{H}} \]

Q-function is linearly representable:

\[ Q^\pi_h(s_h,a_h) = r(s,a) + \int T(s_{h+1}|s_h,a_h)V^\pi_{h+1}(s_{h+1})\,ds_{h+1} = \Bigl\langle \phi(s,a),\, \underbrace{\theta_r + \textstyle\int V^\pi_{h+1}\,\mu(s_{h+1})\,ds_{h+1}}_{w}\Bigr\rangle_{\mathcal{H}} \]
KeyNot a special model, but a generic structure.

Control
Planning for stochastic nonlinear control

Given an arbitrary bounded nonlinear \(f\), construct \(\phi(s,a)\) for value functions; then optimize by linear dynamic programming in the obtained space.

Least-squares policy evaluation

for \(t=0,\dots,T-1\):
\[ \hat w_{k,t+1} = \arg\min_w \sum_{i}\Bigl(\phi(s_i,a_i)^\top w - r(s_i,a_i) - \gamma\,\phi(s_i',a_i')^\top \hat w_{k,t}\Bigr)^2 \]

Natural policy gradient for control

\[ \theta_{k+1} = \theta_k + \eta\,\hat w_{k,T} \]
\[ \pi_{k+1}(a|s) \propto \exp\bigl(\phi(s,a)^\top\theta_{k+1}\bigr) \]

Ren et al., CDC 2023 / IEEE TAC 2025

RL with Linear Representation
Learn \(\phi(s,a)\) from data — tractably — then explore and plan linearly.
Linear MDP
Spectral view of MDPs
\[ T(s'|s,a) \propto \exp\Bigl(-\frac{\|s'-f(s,a)\|_2^2}{2\sigma^2}\Bigr) = \bigl\langle \phi_\omega(f(s,a)),\,\phi_\omega(s')\bigr\rangle_{\mathcal{N}(0,\sigma^{-2}I)} \]

Generalize: learn the factorization directly instead of fixing the kernel.

\[ \boxed{\;T(s'|s,a) = \langle\phi(s,a),\,\mu(s')\rangle,\qquad r(s,a) = \langle\phi(s,a),\,\theta_r\rangle\;} \]

The MLE of \(T\) under this constraint is intractable — four tractable surrogates follow.

Spectral Representation-based RLLinear MDP · 21
Linear MDP · Contrastive
Contrastive representation (NCE / CPC)

A contrastive loss as a tractable alternative to the MLE:

\[ (s,a,s')\sim\mathcal{D},\qquad s_l\sim p(s') \]
\[ \max_{\phi,\mu}\;\hat{\mathbb{E}}\Bigl[\langle\phi(s,a),\mu(s')\rangle - \log\sum_l \langle\phi(s,a),\mu(s_l')\rangle\Bigr] \]

The objective leads to the solution

\[ T(s'|s,a) = \bigl\langle \phi(s,a),\; {\color{#3b82f6}p(s')}\,\mu(s')\bigr\rangle \]

Zhang, Ren et al., ICML 2022 (CTRL)

Spectral Representation-based RLLinear MDP · 22
Linear MDP · SVD
Spectral decomposition representation (SVD)

SVD as a tractable alternative to the MLE:

\[ T(s'|s,a) = \langle\phi(s,a),\,{\color{#3b82f6}p(s')}\mu(s')\rangle \;\;\Rightarrow\;\; \frac{T(s',s,a)}{\sqrt{p(s,a)}\sqrt{p(s')}} = \sqrt{p(s,a)}\sqrt{p(s')}\,\phi(s,a)^\top\mu(s') \]

SVD decomposition

\[ \int\Bigl\|\frac{T(s',s,a)}{\sqrt{p(s,a)}\sqrt{p(s')}} - \sqrt{p(s,a)}\sqrt{p(s')}\,\phi(s,a)^\top\mu(s')\Bigr\|^2 d(s,a)\,ds' \]
\[ \propto\; -2\,\mathbb{E}_{T(s',s,a)}\bigl[\phi(s,a)^\top\mu(s')\bigr] + \mathbb{E}_{p(s,a)p(s')}\bigl[(\phi(s,a)^\top\mu(s'))^2\bigr] \]
a simple, unbiased SGD objective

Ren, Zhang et al., ICLR 2023 (SPEDE)

Spectral Representation-based RLLinear MDP · 23
Linear MDP · Latent Variable
Latent variable models are linear MDPs
\[ T(s'|s,a) = \int p(s'|z)\,p(z|s,a)\,dz = \bigl\langle p(z|s,a),\, p(s'|z)\bigr\rangle_{L_2} \]
\[ \phi(s,a) = p(z|s,a),\qquad \mu(s') = p(s'|z) \]

Evidence lower bound (ELBO)

\[ \begin{aligned} \log T(s'|s,a) &= \log\int p(s'|z)\,p(z|s,a)\,dz \\ &= \max_{q\in\Delta(\mathcal{Z})}\;\mathbb{E}_q\bigl[\log p(s'|z)\bigr] - KL\bigl(q(z|s,a,s')\,\|\,p(z|s,a)\bigr) \end{aligned} \]

Ren, Xiao et al., ICLR 2023 (LV-Rep)

Spectral Representation-based RLLinear MDP · 24
Linear MDP · Diffusion
Diffusion spectral representation

Connect the diffusion model with a spectral decomposition of the MDP:

\[ T(s'|s,a) \propto \exp\bigl(\psi(s,a)^\top\upsilon(s')\bigr) = \bigl\langle \phi_\omega(\psi(s,a)),\, \nu_\omega(\upsilon(s'))\bigr\rangle \]

Score-based representation learning

\[ \min_{\psi,\upsilon}\;\mathbb{E}_\beta\,\mathbb{E}_{s,a,s',\tilde s'}\Bigl[\bigl\|\tilde s' + \beta\,\psi(s,a)^\top\nabla_{\tilde s'}\upsilon(\tilde s',\beta) - \sqrt{1-\beta}\,s'\bigr\|^2\Bigr] \]

Shribak et al., NeurIPS 2024 (Diff-SR)

Spectral Representation-based RLLinear MDP · 25
Linear MDP · Algorithm
The algorithm
  1. Collect data   \(s\sim d^{\pi_n},\; a\sim U(\mathcal{A}),\; s'\sim T(\cdot|s,a)\);   \(\mathcal{D}_n = \mathcal{D}_{n-1}\cup\{s,a,s'\}\)
  2. Learn representation via NCESVDELBODiffusion
  3. (Optional) UCB bonus
    \[ \hat b_n(s,a) = \alpha_n\sqrt{\hat\phi_n(s,a)^\top\hat\Sigma_n^{-1}\hat\phi_n(s,a)},\qquad \hat\Sigma_n = \textstyle\sum_{(s,a)\in\mathcal{D}_n}\hat\phi_n(s,a)\hat\phi_n(s,a)^\top + \lambda_n I \]
  4. Policy evaluation with Bellman recursion
    \[ Q^\pi(s,a) = r(s,a) + \hat b_n(s,a) + \gamma\,\mathbb{E}_P\bigl[V^\pi(s')\bigr] \]
  5. Policy optimization with the learned \(Q\); repeat.

POMDP
Partially observable MDPs

\(\mathcal{P} = \langle\mathcal{S},\mathcal{A},\mathcal{O},r,H,\rho_0,T,O\rangle\)

HardComputation: PSPACE-complete (Papadimitriou & Tsitsiklis, 1987).  Statistics: exponential in the horizon (Jin et al., 2020a).
But not allStructured POMDPs admit efficient sample complexity (Jin et al., 2020a; Golowich et al., 2022; Liu et al., 2022, 2023; Efroni et al., 2022; Guo et al., 2023).
Spectral Representation-based RLPOMDP · 34
POMDP
\(L\)-decodable POMDPs
Definition (\(L\)-decodability, Efroni et al., 2022).  Define \[ x_t \in \mathcal{X} := (\mathcal{O}\times\mathcal{A})^{L-1}\times\mathcal{O},\qquad x_t = (o_{t-L+1}, a_{t-L+1},\dots,o_t). \] A POMDP is \(L\)-decodable if there exists a decoder \(p:\mathcal{X}\to\Delta(\mathcal{S})\) such that \(p(x_t) = s_t\).

The \(L\)-step window is a sufficient statistic for the state — e.g. frame stacking in visual RL.

Spectral Representation-based RLPOMDP · 35
POMDP
Spectral representation of the \(L\)-step dynamics

\(L\)-decodability lets the value live on the window \(x_t\) — an \(L\)-step Bellman equation:

\[ Q^\pi(x_t,a_t) = \mathbb{E}_{x_{t+1:t+L}\sim\mathbb{P}^\pi(\cdot|x_t,a_t)}\Bigl[\textstyle\sum_{i=0}^{L-1}\gamma^i r_{t+i} + \gamma^L V^\pi(x_{t+L})\Bigr] \]

A moment-matching policy \(\tilde\pi\), conditioned only on \((x_t,a_t)\), removes the intermediate steps.

Spectrally decompose the \(L\)-step transition and reward:

\[ \mathbb{P}^{\tilde\pi}_L(x_{t+L}|x_t,a_t) = \bigl\langle \phi(x_t,a_t),\, \mu^{\tilde\pi}(x_{t+L})\bigr\rangle_{\mathcal{H}},\qquad r^{\tilde\pi}_L(x_t,a_t) = \textstyle\sum_{i=0}^{L-1}\gamma^i r_{t+i} = \bigl\langle \phi(x_t,a_t),\, \theta_r^{\tilde\pi}\bigr\rangle_{\mathcal{H}} \]
\[ \boxed{\;Q^\pi(x_t,a_t) = \bigl\langle \phi(x_t,a_t),\; \theta_r^{\tilde\pi} + \gamma^L\textstyle\int \mu^{\tilde\pi}(x_{t+L})\,V^\pi(x_{t+L})\,dx_{t+L}\bigr\rangle_{\mathcal{H}}\;} \]
Beyond LV\(\phi(x_t,a_t)=p(z|x_t,a_t)\) (μLV-Rep) is just one instance.
